# Мост

Android-приложение для доступа к заблокированным ресурсам. **Split-tunneling VPN**: через прокси идёт только трафик к заблокированным ресурсам, всё остальное — напрямую.

## Скачать

[**Most-0.5.4.apk**](Most-0.5.4.apk)

## Возможности

- Подписки по ссылке (`vless://`, `hysteria2://`, `trojan://`, `ss://`, WireGuard)
- Автовыбор самого быстрого сервера
- Автопроверка доступности YouTube, Telegram, Instagram при подключении — переключение на рабочий сервер
- Split-tunneling: только заблокированные IP через VPN
- Ручной выбор сервера (с подтверждением)
- Работает через sing-box ядро
